# 书桌背面：回声档案

## 已包含的内容

博客内 /echoes/ 路由，4 卷互动叙事、17 份一般档案与 1 份隐藏档案、4 道依靠故事线索的校对题、线索簿、控制台、3 个结局，以及浏览器本地存档。

它是 ARG 风格的互动虚构小说，尚未扩展为跨网站、跨现实场所的完整社群 ARG。内容取材于公开文章的主题，但对话和人物情节均为虚构改编；没有公开真实私人聊天记录。

## 路由与代码

- src/pages/echoes/index.astro：游戏页，复用博客的 Layout、Navbar、Footer。
- src/styles/echoes.css：响应式档案界面和手机适配。
- src/scripts/echoes-game.js：故事文本与状态、提示、解谜、结局逻辑。
- src/components/features/posts/DeskIntro.astro：首页游戏入口。
- scripts/prune-sayori-diary.mjs：独立日记站构建移除该路由。

本作品不依赖数据库或账号，也不调用外部 AI API。进度仅留在当前浏览器 localStorage，存储键名为 amiya.echoes.v1。可在游戏内重置。

## 章节与测试答案（作者专用，包含剧透）

1. 访客：从维护记录发现首次创建日期，答案 0521。
2. 追赶：按日期排序四封信 B、D、A、C，答案 2413。
3. 两份记录：寻找重复意象，答案 灯。
4. 未完：校对两个矛盾但都真实的想法，答案 都是真的。

最后一卷可在控制台执行 find future 解锁一份隐藏便签。测试命令包括 help、ls、status、hint、open system。

结局选项为寄给世界、放回抽屉、继续写下去，可重复选择。

## 部署与验收

沿用博客原有 Astro 和 Cloudflare Pages 构建流程。开发环境执行 pnpm install --frozen-lockfile，随后 pnpm dev，访问 http://localhost:4321/echoes/。生产环境执行仓库已有的 pnpm run build，不需要额外服务。

合并 PR 前请检查：
- 从首页进入游戏并完成四卷。
- 移动端阅读、解谜输入和滚动。
- 刷新后自动恢复存档；重置后回到初始状态。
- 使用浏览器后退返回游戏，确保 Astro client-side navigation 正常初始化。
- 使用线索簿回看已读档案，并找到隐藏档案。
- 确认多语言构建以及独立日记站构建没有泄露多余页面。

当前仅完成代码级 JavaScript 语法校验，尚未完成真实浏览器端与完整生产构建验收。PR 默认草稿，供审核后再上线。

## 后续可拓展的方向

将真实公开文章作为引导入口、建立专用虚构 Git 历史、添加声音与不同视角的记忆，逐步变成更广义的 ARG。不要让玩家误以为真实私人档案泄露，也不要要求玩家联系真人、猜测真实账户密码或前往危险场所。私人聊天或日记的任何采用都必须经过手动挑选和改编。

需要增加章节时先调整脚本中的 records、chapters、endings 三组数据；如果扩展到更多卷，拆分状态逻辑与内容数据并补充自动化测试。
